 # Steady: Tremor Filtering Accessibility Tool

  ## Overview

  Steady is an adaptive tremor filtering application designed to assist
  users with motor control challenges. The tool provides improved cursor
  control for individuals experiencing tremors, making computer interaction
  more precise and manageable.

  ## Features

  - Multiple tremor profile support
  - Machine learning-based adaptation
  - Cross-platform compatibility
  - Customizable smoothing parameters
  - Adaptive filtering algorithm

  ## Installation
